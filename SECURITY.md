# Maskit Security Documentation

## 4. Compliance Alignment

### GDPR (General Data Protection Regulation)

- Data Minimization: Only collects necessary data (user settings/counters)
- Right to Erasure: Settings can be reset at any time
- No Cross-Border Transfer: All processing occurs locally

### HIPAA Alignment

- Privacy by Design: Encryption-ready architecture
- Data Handling: No PHI storage unless explicitly handled by user
- Audit Log: Tamper-evident through hash chaining

### Clinical Data Protection

- Compatible with healthcare applications handling HIPAA-regulated data
- No inference of sensitive health information from patterns

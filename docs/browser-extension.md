# Browser Extension

Maskit supports these exact host patterns: `https://chatgpt.com/*`, `https://chat.openai.com/*`, `https://claude.ai/*`, `https://gemini.google.com/*`, `https://copilot.microsoft.com/*`, and `https://*.cursor.com/*`.

The extension scans paste, copy, and typing events locally. Configure detection toggles, site allow/block lists, redaction format, custom rules, policies, audit retention, and pause behavior from `options.html`.

# MCP Security Gateway Direction

The MCP gateway is a future adapter built on the unified context model. Its control points are:

- tool allowlists and deny lists
- context filtering before a tool call
- approval workflows for high-risk actions
- trust metadata for tools and servers
- response scanning before content returns to the client

The current MCP server already exposes scan, redact, policy, response, rules, status, and audit tools. Gateway enforcement is not yet marketed as shipped functionality.

Maskit Privacy Policy

Last updated: July 28, 2026

Local processing only. Maskit helps reduce accidental exposure of sensitive data. It does not guarantee protection. Detection happens locally in the browser and connected local adapters. We do not collect, transmit, or sell your page content or clipboard data.

Supported sites

Maskit currently runs on these configured host patterns: https://chatgpt.com/*, https://chat.openai.com/*, https://claude.ai/*, https://gemini.google.com/*, https://copilot.microsoft.com/*, and https://*.cursor.com/*. Gmail is not supported by the browser extension.

What Maskit accesses

  • Text you paste, copy, or type on supported pages while the extension is active
  • Your extension settings, including toggles, site filters, and custom regex rules
  • Aggregate redaction counters and locally stored audit metadata
  • The hostname of the current tab to apply site allow/block lists

What Maskit does not do

  • Send page content, clipboard text, or detected values to external servers
  • Store raw matched text in browser statistics or audit events
  • Track browsing history for advertising
  • Read the clipboard outside paste/copy events you trigger

Data storage

The browser extension stores settings, counters, and audit metadata locally using chrome.storage.local. It does not use chrome.storage.sync or sync settings through a Google account.

Local MCP and desktop integrations may store configuration and audit records in their configured local files. These records remain on the device unless you move or back them up yourself.

Clipboard behavior

Maskit inspects clipboard text only during supported paste or copy events in active editors. The Windows agent may monitor clipboard updates when that optional local component is enabled.

Custom regex rules

Rules you create are stored in settings and executed locally. Maskit rejects overly long or potentially unsafe regex patterns.

Permissions

  • storage — save settings, counters, and local audit metadata
  • host permissions — run on the supported AI host patterns listed above

Contact

For privacy questions, contact the extension publisher through the Chrome Web Store listing support channel.

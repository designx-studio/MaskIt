How it runs

Same rules, three different doors.

Detection logic is shared across browser, MCP, and Windows workflows.

01

You type or paste

The content script watches supported AI hosts.

02

Local scan

Pattern and validator checks run in-browser before submission.

03

Swap or warn

Matches are redacted in place or held for review.

01

A client calls a tool

Claude Desktop, Cursor, or another MCP client invokes local tools.

02

Node scans locally

The server applies saved configuration without external API calls.

03

Structured result

Findings, risk, redaction, and audit information return to the client.

01

Clipboard changes

The tray agent listens for clipboard updates.

02

Policy applies

The active workflow is evaluated against local rules.

03

Clipboard rewritten

Sensitive matches are replaced and logged locally.

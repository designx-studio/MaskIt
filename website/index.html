Chrome Extension · v2.1

Stop accidental data leaks before you hit send.

Maskit helps reduce accidental exposure of sensitive customer data on ChatGPT and Gmail. Everything runs locally in your browser — nothing is uploaded.

Built for real support workflows

Paste, copy, and typing

Redacts sensitive values whether they arrive from the clipboard or are typed slowly between words.

ChatGPT + Gmail ready

Uses editor-aware insertion so rich text fields stay stable instead of breaking mid-compose.

API keys and PII

Detects OpenAI, Stripe, GitHub, AWS, emails, cards, SSNs, and your own custom regex rules.

Review before redact

Optionally confirm what will be removed before Maskit replaces anything.

Site controls

Run everywhere, or limit protection to an allowlist or blocklist per domain.

Private by design

Everything runs locally. No page content is sent to a server.

Install in 3 steps

1. Load unpacked

Open chrome://extensions, enable Developer mode, and load the Maskit folder.

2. Pin Maskit

Click the puzzle icon and pin Maskit. The toolbar badge shows ON when a page is protected.

3. Try a paste

Paste john@example.com or an API key into ChatGPT and watch it redact instantly.

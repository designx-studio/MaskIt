How it runs

Same rules, three different doors.

Detection logic is shared; how it's invoked depends on where you're working.

01

You type or paste

Into any of the 6 supported AI hosts — a content script watches the input field directly.

02

Local scan, same tick

Pattern + validator checks run in-browser before the keystroke or paste completes.

03

Swap or warn

Matches get redacted in place, or held for review if "review before redact" is on.

01

A client calls a tool

Claude Desktop, Cursor, or any MCP-compatible client invokes scanning and redaction functions.

02

Local Node process scans

The MCP server runs on your machine and applies your saved config — no external API call.

03

Structured result returned

Findings, risk score, and redacted text come back to the calling client; the event is logged locally.

01

Clipboard changes

The tray agent listens for Windows clipboard-update events system-wide.

02

Foreground app is checked

The active process is classified (AI tool, local model, other) to apply the right policy.

03

Clipboard is rewritten

Sensitive matches are replaced in place; a hash-chained local audit entry is written.

Beyond detection

Detection is the easy part. This is the rest.

Role-based policies

Set allow, redact, or block per data type — and override it per app or per site. A card number can be blocked on chatgpt.com and allowed inside your own local model.

EMAILredact
API_KEYredact
CARDblock
SSNblock

Hash-chained audit log

Every redact, block, and allow decision is logged locally with a chained hash — each entry references the previous one, so a tampered log is detectable. Export to CSV, set your own retention window.

14:02:11EMAIL · redacted
14:02:44CARD · blocked
14:03:09API_KEY · redacted

Admin killswitch

Restrict AI tools entirely, on a schedule or for a fixed duration — useful for orgs enforcing "no AI tools during code review" windows without policing it manually.

Mon–Fri09:00–17:00 restricted
Weekendsunrestricted

Unmask, on the record

Need to see a masked value again? Reveal it for 30 seconds — every unmask is written to the audit trail, so "who looked at what, when" is always answerable.

Beta

A tray agent for the rest of Windows.

Browser extensions only see the browser. The Windows agent watches the system clipboard, so a copy into a desktop AI client gets the same protection.

  • .NET 8, runs from the system tray — green / amber / red status at a glance
  • Clipboard-only scope by design; it does not read keystrokes or screen content
  • Shares the exact same rule set as the browser and MCP server via maskit-core
  • Verified against the same fixture suite in CI before every release

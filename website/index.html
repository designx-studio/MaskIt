The problem

AI makes context a new security boundary.

People and agents can move customer data, credentials, source code, and internal context into tools faster than traditional controls can review it.

Prompt leakage

Secrets and personal data enter public AI tools through ordinary typing and paste flows.

Agent access

Tools and resources let AI systems read and act beyond the chat window.

Policy drift

Browser, desktop, CLI, and MCP workflows often use different rules.

Missing evidence

Security teams need decisions and outcomes without collecting the raw secret.

The control model

One policy decision, close to the source.

Maskit currently detects, validates, applies allow, redact, or block actions, and records local evidence. Simulation, file controls, and agent permissions are planned next.

Architecture

Keep enforcement local. Add management carefully.

The current engine stays on the device. Future management will distribute policy, device state, and non sensitive evidence. Raw prompts, clipboard contents, files, and secret values remain local by default.

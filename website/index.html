Detection engine
What Maskit detects
PII
Email, phone, SSN, passport, and IP address patterns.
Financial
Cards with Luhn validation, IBAN/bank accounts, and M-Pesa references.
Secrets
30+ named API-key and secret patterns across OpenAI, Anthropic, AWS, GCP, Azure, GitHub, GitLab, Slack, Stripe, Twilio, SendGrid, Cloudflare, Auth0, Firebase, Docker Hub, and Terraform.
Custom rules
Locally executed regex rules with length and unsafe-pattern checks.


Beyond detection
Controls built for real teams
Policies
Per-app and per-context allow, redact, or block actions.
Audit log
Local structured events with hashed tokens, chain hashes, retention controls, and browser CSV export.
Killswitch
Admin-configurable duration or schedule restrictions for AI tools.
Audited unmask
Temporary value access can be tracked in the local audit trail.

Windows agent
Clipboard protection in beta
.NET 8 beta. The Windows tray agent monitors clipboard updates locally, applies the shared rules and policies, and writes local audit records. It does not inspect data that never reaches the clipboard. Read the agent docs.

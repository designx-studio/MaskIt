The problem

AI makes accidental exposure one paste away.

Employees move quickly. A support ticket becomes a prompt. A copied stack trace carries an API key. A customer export gets uploaded to diagnose a bug. The intent is helpful. The data should never have left the endpoint.

MaskIt adds a local checkpoint before that handoff.

Privacy model

Your prompts are never sent to MaskIt servers.

MaskIt is designed to run at the point where sensitive data leaves your control. The core processing stays with the adapter on your device or runner.

✓Local processing in the browser, CLI, MCP, VS Code, and Windows agent
✓No cloud inspection or prompt collection
✓No customer documents uploaded to MaskIt
✓Audit events exclude raw matched content
✓Works without a MaskIt cloud account

# Recording the Maskit demo video

Maskit ships with a self-playing HTML demo you can screen-record for marketing or the Chrome Web Store listing.

## Open the demo

1. Open `website/demo.html` in Chrome (double-click or drag into a browser tab).
2. Click **Replay** if you want to restart the animation.
3. Optionally open `website/index.html` for the hero-page animation.

## Recommended recording setup

- Resolution: 1920×1080 or 1280×720
- Browser: Chrome with a clean profile and dark theme
- Hide bookmarks bar and extensions you do not want visible
- Zoom the page to 110% if text looks small on video

## Windows (Xbox Game Bar)

1. Open `website/demo.html`
2. Press `Win + G`
3. Click Record
4. Let the demo loop 2–3 times
5. Save as `website/maskit-demo.mp4`

## macOS (QuickTime)

1. Open QuickTime → File → New Screen Recording
2. Record the demo window for 20–30 seconds
3. Export as `website/maskit-demo.mp4`

## After recording

- Trim the clip to one clean loop
- Add a short title card: “Maskit — redact sensitive data before you send”
- Upload to your site or Chrome Web Store media section

The HTML demo is a stand-in until a filmed product capture is available.

Install the boundary, not the source tree.

Every package below points to the latest production release. Download it, follow the component guide, and start protecting AI work without compiling the repository.

Browser extension

Load the package for your browser to protect supported AI hosts. Chrome, Edge, Firefox, and Opera builds are generated from the same extension source.

Chrome ZIPEdge ZIPFirefox ZIPOpera ZIP
Install

Extract the ZIP, open your browser's extensions manager, enable developer mode when required, choose Load unpacked, and select the extracted folder.

Read browser installation

Windows agent

A self-contained Windows x64 package for local clipboard protection. The release workflow publishes the built agent together with its usage guide.

Windows ZIP
First run

Extract the ZIP, run the published agent executable, and follow the configuration notes in the Windows guide.

Read Windows agent setup

MCP server

Run Maskit's local tools inside Claude Desktop, Cursor, or another compatible MCP client. The package includes the server, engine, configuration, and tests.

MCP TAR.GZ
Installtar -xzf maskit-mcp.tar.gz
cd maskit-mcp
npm ci

Use the included configuration example for Claude Desktop or Cursor.

Read MCP setup

CLI

Use the local scanner from scripts, CI helpers, or a terminal workflow. Scan text and files, redact findings, and assess risk.

CLI TAR.GZ
Installtar -xzf maskit-cli.tar.gz
cd maskit-cli
npm ci

Examples include node mcp-server/cli.js scan "text" and node mcp-server/cli.js redact "text".

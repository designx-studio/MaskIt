Get Maskit

Build locally or download release artifacts from GitHub.

Browser extension

Build Chrome, Edge, Opera, or Firefox packages with npm run build:chrome or the equivalent browser script.

MCP server and CLI

Install from source with Node.js 18+: cd mcp-server && npm ci.

Windows agent

Requires Windows and .NET 8. See the Windows agent guide.

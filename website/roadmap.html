Product roadmap

From local redaction to the AI context firewall.

Maskit controls what humans and AI agents can share, access, and execute. The roadmap stays focused on that boundary, instead of turning Maskit into generic DLP.

Phase 1, production launch

Now

Make the current product trustworthy

Release real browser, MCP, CLI, and Windows packages. Stabilize install paths, documentation, detection fixtures, policy contracts, privacy claims, audit behavior, and GitHub distribution.

Phase 2, AI data protection platform

3 to 9 months

Turn detection into a team policy product

Improve detection quality, explanations, confidence, custom rules, policy bundles, simulation, CI workflows, signed configuration, audit exports, and managed pilot controls.

Phase 3, AI context firewall

9 to 18 months

Govern context and tool actions

Extend the local MCP server into a gateway for tool permissions, server trust, file and repository controls, context filtering, approvals, and agent activity evidence.

Phase 4, enterprise platform

18 to 24+ months

Centralize policy without centralizing raw prompts

Add organization policy management, device enrollment, SSO, staged rollout, risk views, compliance exports, SIEM integrations, and managed deployment once local enforcement is proven.

Build first

Detection trust

Accuracy, explanations, fixtures, false-positive suppression, and consistent behavior across surfaces.

Policy contracts

A deterministic pipeline for detection, classification, decision, transformation, and evidence.

Local gateway

MCP and agent controls that extend the same policy boundary to tools, files, repositories, and context.

Do not chase yet

Do not compete with broad network DLP, universal SaaS discovery, full endpoint management, or a cloud dashboard before Maskit has reliable local enforcement and paying design partners.

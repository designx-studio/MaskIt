SECURITY TRUST CENTER

Local enforcement, honest boundaries.

Maskit is a defense-in-depth tool for reducing accidental exposure of sensitive context. It does not guarantee that every secret, policy violation, or unsafe action will be detected.

Threat model

Maskit is designed to reduce accidental disclosure from typing, paste, copy, clipboard updates, CLI inputs, MCP requests, and AI responses. It is not a secure browser, antivirus, phishing product, cloud proxy, or AI model provider.

Privacy architecture

Local by default

Detection and policy evaluation run in the browser extension, local Node process, CLI, or Windows agent.

No raw value in audit events

Audit metadata can include type, action, app, severity, and a salted hash token. Raw matched values are not intended to be stored.

Explicit controls

Policies can allow, redact, or block. Review and pause behavior are visible settings, not hidden background actions.

Known limitations

Pattern detectors can miss novel formats and may produce false positives. Business context classification is not yet a full semantic classifier.

Data handling

  • Page content and clipboard text are processed locally by the active adapter.
  • Configuration and audit files are written locally by MCP, CLI, and desktop components.
  • Maskit does not claim SOC 2, ISO 27001, GDPR certification, or other compliance certification.
  • Review permissions, deployment settings, and custom rules before production use.

Report a security issue

Use the repository's security reporting process or contact the publisher through the support channel.

Maskit Security Model

Maskit keeps detection local across the browser, MCP, CLI, and Windows agent.

No cloud scanning

Requests are inspected on the local adapter before transmission.

No prompt storage

Raw matched values are not stored in browser statistics or audit events.

Policy controls

Per-app actions can allow, redact, or block sensitive categories.

Auditability

Local audit events use hashed sensitive tokens and chain hashes.
